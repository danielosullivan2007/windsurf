# Casino Game Review Embedding Analysis

## Project Overview
We analyzed 3,549 casino games using advanced natural language processing techniques, specifically:
- OpenAI embeddings of game reviews
- K-means clustering algorithm
- 3-dimensional t-SNE for dimensionality reduction

## Clustering Methodology
- **Total Games Analyzed**: 3,549
- **Number of Clusters**: 9
- **Dimensionality Reduction**: 3D t-SNE transformation
- **Feature Extraction**: Review text embeddings
